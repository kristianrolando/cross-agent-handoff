# Cross-Agent Handoff v0.2.3

A small fix release for items deferred from v0.2.2. The checkpoint format stays
`cross-agent-handoff/1` and the routing block is unchanged; nothing new needs enabling.

## What's new

- **Hook paths safer on Windows and unusual folders.** Claude Code hook commands now use
  `${CLAUDE_PROJECT_DIR}`, the form Claude Code rewrites for PowerShell. `hooks.py install`
  refuses a path containing `$` or a backtick, which a shell would expand, and `status` reports
  entries written for such a path by an older version.
- **No traceback on a damaged manifest.** `install.py` reports an unreadable `MANIFEST.sha256`
  and `--update` rewrites it.
- **`handoff.py save` shows warnings.** The same advisory warnings as `check` appear in the JSON
  result and on stderr; the save still succeeds with exit code 0.
- **Editing guidance.** `SKILL.md` asks for an edit tool that fails when the old text is missing,
  and a reread after any full-file rewrite.

## Upgrading from v0.2.2

- No migration is required. Update every installed copy together:
  `python3 SKILL/scripts/install.py --project PROJECT --hosts HOSTS --update`.
- If you installed hooks, run `hooks.py install --host claude --yes` again to move existing
  entries to the braced `${CLAUDE_PROJECT_DIR}` form; the old form still runs on macOS and Linux.
- Your routing block does not change.

## Install

Claude Code plugin:

```text
/plugin marketplace add kristianrolando/cross-agent-handoff
/plugin install cross-agent-handoff@cross-agent-tools
```

Direct skill, with the Skills CLI (Node.js 22.20+):

```sh
npx skills add kristianrolando/cross-agent-handoff --skill cross-agent-handoff
```

Or with the bundled installer (Python 3.9+), from a checkout:

```sh
python3 skills/cross-agent-handoff/scripts/install.py --project /path/to/project --hosts claude,codex,antigravity
```

## Validation and limits

The package suite (93 tests) passed locally on macOS with Python 3.9.6 and 3.15.2. Each new test fails on
v0.2.2's scripts and passes here. A hook command was run through `/bin/sh -c`; the PowerShell
rewrite of `${CLAUDE_PROJECT_DIR}` is taken from Claude Code's documentation and was not run on
Windows. Hosted results are recorded in [validation.md](../validation.md).
