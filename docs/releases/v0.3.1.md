# Cross-Agent Handoff v0.3.1

Four small fixes from the audit of v0.2.1. The checkpoint format stays `cross-agent-handoff/1`;
the routing block and guidance are unchanged.

## What's fixed

- **Config typos no longer silence `inject`.** A wrongly typed value in `.handoff/config.json` is
  ignored with a warning naming the key.
- **`save` keeps the file mode** instead of leaving `HANDOFF.md` at 0600.
- **Lock details.** `--host` rejects emails and free text; the lock folder's `.gitignore` also
  covers a crashed save's temporary file and handles a missing final newline.
- **Large files.** `inspect` and `observed_file` checks hash in 1 MB chunks, not all in memory.

## Upgrading from v0.3.0

- No migration is required. Update every installed copy together:
  `python3 SKILL/scripts/install.py --project PROJECT --hosts HOSTS --update`.

## Install

Claude Code plugin:

```text
/plugin marketplace add kristianrolando/cross-agent-handoff
/plugin install cross-agent-handoff@cross-agent-tools
```

Direct skill, with the Skills CLI (Node.js 22.20+):

```sh
npx skills add kristianrolando/cross-agent-handoff --skill cross-agent-handoff
```

Or with the bundled installer (Python 3.9+), from a checkout:

```sh
python3 skills/cross-agent-handoff/scripts/install.py --project /path/to/project --hosts claude,codex,antigravity
```

## Validation and limits

The package suite (103 tests) passed locally on macOS with Python 3.9.6 and 3.15.2; each of the
five new tests fails on v0.3.0's scripts. The file-mode test is skipped on Windows. The chunked
hash was checked for equality and for never calling `read_bytes`, not for memory use on a 1 GB
file. These fixes were rewritten from the audit's findings after the original patches were lost. Hosted
checks (Ubuntu, macOS and Windows on Python 3.9 and 3.14) passed on the pull request; the Windows jobs
ran the tests, not an agent session on Windows.
