# Cross-Agent Handoff v0.3.0

Compaction and the clock, measured in a live trial, plus tools that say where a checkpoint is long.
The checkpoint format stays `cross-agent-handoff/1`; nothing new needs enabling.

## What's new

- **Routing block, 27 words longer.** Agents are asked to take `updated_at` from
  `date -Iseconds` and never estimate it, and to compact HANDOFF.md in the same save when it is
  over 1,200 words, keeping open items, decisions and failed attempts. In a synthetic trial the
  checkpoint stayed within 1,300 words in 13 of 13 runs with the new block against 6 of 13 with the
  previous one, and `updated_at` was real in 13 of 13 against 7 of 13. See
  [the record](../evidence/live-trial-2026-11-26-routing-block-v2.md) for method and limits.
- **Where a checkpoint is long.** `check`, `save` and the resume context name prose before the
  first section, sections outside the template, long Recent outcomes and Next, and the largest
  sections. Advisory only.
- **Doctor knows the plugin.** `install.py --doctor` reports an enabled Claude plugin instead of
  "No installed copy found" and warns when a `.claude/skills` copy would be listed twice.
- **Guidance.** Copy the checkpoint before a large compaction; the video profile keeps only the
  latest output; host memory is not the owner of decisions.

## Upgrading from v0.2.3

- No migration is required. Update every installed copy together:
  `python3 SKILL/scripts/install.py --project PROJECT --hosts HOSTS --update`.
- To get the new rules, replace your routing block with the one in `references/setup.md` after
  reviewing local edits. The old block keeps working.

## Install

Claude Code plugin:

```text
/plugin marketplace add kristianrolando/cross-agent-handoff
/plugin install cross-agent-handoff@cross-agent-tools
```

Direct skill, with the Skills CLI (Node.js 22.20+):

```sh
npx skills add kristianrolando/cross-agent-handoff --skill cross-agent-handoff
```

Or with the bundled installer (Python 3.9+), from a checkout:

```sh
python3 skills/cross-agent-handoff/scripts/install.py --project /path/to/project --hosts claude,codex,antigravity
```

## Validation and limits

The package suite (98 tests) passed locally on macOS with Python 3.9.6 and 3.15.2. The trial used
one model on one host with a synthetic project; it shows what these agents did there, not what
real projects will do. Hosted checks (Ubuntu, macOS and Windows on Python 3.9 and 3.14) passed on the
pull request; the Windows jobs ran the tests, not an agent session on Windows. No second host was run:
the Antigravity CLI refused shell commands in headless mode without disabling its permission checks.
