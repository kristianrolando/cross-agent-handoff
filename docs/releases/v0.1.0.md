# Cross-Agent Handoff v0.1.0

Continue a project across Claude Code, Codex and new sessions using the project files as the source of truth.

## Included

- Initialize, resume, checkpoint, handoff and recovery procedures.
- One compact checkpoint template and optional standard-library Python helper.
- Claude Code plugin/catalog and direct skill installation for Codex.
- Shared contributor instructions for humans, Claude Code and Codex.
- Quick start, before/after examples and compatibility documentation.
- MIT license in both the repository and standalone skill.
- Automated protocol/package checks with a hosted Linux/macOS/Windows matrix.

## Install

Claude Code plugin:

```text
/plugin marketplace add kristianrolando/cross-agent-handoff
/plugin install cross-agent-handoff@cross-agent-tools
```

Direct skill installation, including Codex:

```sh
npx skills add kristianrolando/cross-agent-handoff --skill cross-agent-handoff
```

The skills CLI installer requires Node.js 22.20+; manual copying is also supported. The core workflow requires ordinary filesystem access and no vendor API, cloud service or IDE. Python 3.9+ is needed only for the optional helper.

## Scope

This is a sequential handoff workflow. It does not promise emergency saves before a crash, automatic cross-device synchronization or locking of overlapping source edits. Maintainer-reported successful use and automated evidence are recorded separately in the validation documentation. The Codex route is a skill; no native Codex plugin is advertised.
