# Cross-Agent Handoff v0.1.1

Continue a project across Claude Code, Codex, Antigravity, Cursor, Gemini CLI, GitHub Copilot, OpenCode, Cline and new sessions using the project files as the source of truth.

## Changes since v0.1.0

- Host guide (`references/agents.md`) with project and user skill folders, activation checks and official sources for Antigravity, Cursor, Gemini CLI, GitHub Copilot, OpenCode and Cline, alongside Claude Code and Codex. Other filesystem agents get an explicit-file fallback.
- Folder coverage is stated plainly: `.agents/skills/` and `.claude/skills/` each reach a different set of hosts, so mixed teams may need both copies on the same version.
- Initialization respects the active host's instruction files and adds only a thin pointer where needed. It documents that Claude Code reads `AGENTS.md` only when no `CLAUDE.md` applies, and that Gemini CLI loads only `GEMINI.md` by default.
- Helper: placeholder detection matches only template phrases, so project terms such as SQL `INSERT OR REPLACE` no longer block saves; an existing save lock now explains how to recover.
- README: shorter quick start, per-host initialization prompts and responsive diagrams.
- CI checks whitespace across the committed tree, and the release workflow runs only on an explicit version tag or dispatch.

The checkpoint format stays `cross-agent-handoff/1`. No new runtime dependency, vendor API or background process was added.

## Install

Claude Code plugin:

```text
/plugin marketplace add kristianrolando/cross-agent-handoff
/plugin install cross-agent-handoff@cross-agent-tools
```

Direct skill installation for any supported host:

```sh
npx skills add kristianrolando/cross-agent-handoff --skill cross-agent-handoff
```

The skills CLI installer requires Node.js 22.20+; manual copying is also supported. See the host guide for folders per host.

## Validation and limits

Hosted package checks passed on Linux, macOS and Windows. One live Codex → Antigravity → Codex handoff completed a small task in a disposable project; headless Antigravity could use file tools only. See `docs/evidence/live-trial-2026-11-02.md` for prompts, observations and limits. Cursor, Gemini CLI, GitHub Copilot, OpenCode and Cline routes are documented from official sources but were not exercised live. The workflow is sequential; it does not promise crash-time saves, cross-device synchronization or locking of overlapping source edits.
