# Cross-Agent Handoff v0.2.2

A fix release from an audit of v0.2.1 against four real projects. The checkpoint format stays
`cross-agent-handoff/1`; nothing new needs enabling.

## What's new

- **Routing block, about 34 words longer.** Agents are asked to keep the checkpoint near 1,200
  words, reconcile open items with files, Git and owner answers, save owner questions and answers
  before their final message, take `updated_at` from `date -Iseconds`, check for other writers
  before marking ready, and not rerun a recorded command just to test state.
- **Resume context shows more.** `inject.py` prints running operations written as list items or
  over several lines, and cuts overlong lines.
- **Safer hooks.** Hook scripts exit 0 on invalid arguments; uninstall and doctor handle
  `--shared` Claude hooks; snapshots no longer take Git's index lock and no longer hide modified
  files when Git times out.
- **Clearer `updated_at` errors**, and a README sentence that no longer overstates the lock.

## Upgrading from v0.2.1

- No migration is required. Update every installed copy together:
  `python3 SKILL/scripts/install.py --project PROJECT --hosts HOSTS --update`.
- Your existing routing block keeps working. To get the new rules, replace it with the block in
  `references/setup.md` after reviewing local edits.
- If you used `hooks.py install --shared`, `install.py --uninstall` now removes those entries too.

## Install

Claude Code plugin:

```text
/plugin marketplace add kristianrolando/cross-agent-handoff
/plugin install cross-agent-handoff@cross-agent-tools
```

Direct skill, with the Skills CLI (Node.js 22.20+):

```sh
npx skills add kristianrolando/cross-agent-handoff --skill cross-agent-handoff
```

Or with the bundled installer (Python 3.9+), from a checkout:

```sh
python3 skills/cross-agent-handoff/scripts/install.py --project /path/to/project --hosts claude,codex,antigravity
```

## Validation and limits

The package suite (90 tests) passed locally on macOS with Python 3.9.6 and 3.15.2; hosted checks
cover Ubuntu, macOS and Windows on Python 3.9 and 3.14. Each code fix has a test that fails on
v0.2.1 and passes here. The UTF-8 output change was checked only by simulating a legacy code
page, not on Windows. The routing text has not been tried in a live session: the audit that
motivated it had one reader per variant, so do not read it as proven to change agent behavior.
Evidence and the audit's own limits: [audit-2026-11-26.md](../evidence/audit-2026-11-26.md).
