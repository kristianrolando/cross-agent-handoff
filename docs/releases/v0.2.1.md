# Cross-Agent Handoff v0.2.1

A token-budget release. The checkpoint stays small enough to read on every resume, and saves
between steps cost less. Nothing new to enable; the checkpoint format is unchanged.

## What's new

- **Size warning at resume.** `scripts/inject.py` (and its session-start hook output) now warns
  when the checkpoint exceeds the 1,200-word reading target, so the next agent compacts it.
  Before, only `handoff.py check` and `save` reported it.
- **Cheaper saves between steps.** The skill now asks for in-place updates of the changed
  sections after each step. The full compaction and full reread stay at handoff.
- **Compaction guidance.** The save step states the word target: completed work becomes one
  line linking its changelog, release note, commit or PR, and only the latest result per check
  is kept. Unresolved facts, risks, decisions and failed attempts are never dropped to fit.
- **Shorter routing block.** The block in `references/setup.md` is about a quarter shorter and
  tells agents to skip checkpoint updates for small or read-only tasks.

## Upgrading from v0.2.0

- No migration is required. The format stays `cross-agent-handoff/1`.
- Update every installed copy together:
  `python3 SKILL/scripts/install.py --project PROJECT --hosts HOSTS --update`.
- Your existing routing block keeps working. Replace it with the v0.2.1 block only after
  reviewing local edits.
- If the new warning appears, compact the checkpoint at the next save.

## Install

Claude Code plugin:

```text
/plugin marketplace add kristianrolando/cross-agent-handoff
/plugin install cross-agent-handoff@cross-agent-tools
```

Direct skill, with the Skills CLI (Node.js 22.20+):

```sh
npx skills add kristianrolando/cross-agent-handoff --skill cross-agent-handoff
```

Or with the bundled installer (Python 3.9+), from a checkout:

```sh
python3 skills/cross-agent-handoff/scripts/install.py --project /path/to/project --hosts claude,codex,antigravity
```

## Validation and limits

The package suite (82 tests) passed locally on macOS with Python 3.9; hosted checks cover
Ubuntu, macOS and Windows on Python 3.9 and 3.14. The new behavior is guidance plus one
warning: no live host trial was repeated for this release. Token savings depend on agents
following the guidance; word counts are a reading budget, not a measured token reduction.
